# Changelog

## 0.1.0 — 2026-10-19

- Publish a source-only Pico/PiPER teleoperation and data-capture distribution.
- Add a teal capture-console theme with a dark navigation sidebar, white panels, consistent metrics and keyboard focus styling.
- Preserve the existing page controls, recording state machine, shared frame timing, observation/action schema, ROS topics, motion commands and IK calculations.
- Remove the unused, unlicensed `arm_interfaces` package and its unused include/build references; retain the AgileX ROS driver and messages.
- Remove original camera identities from public defaults and provide an ignored local configuration workflow.
- Verify XR message schemas against a pinned licensed upstream and preserve third-party licenses.
- Add setup/architecture/contribution/security documentation, offline checks and CI.
